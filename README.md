# PetLover – Pet Care Website

## About the Project
PetLover is a frontend website project designed to present pet care services in a simple and user-friendly layout. The website provides information about pet boarding, grooming, feeding, and training.

This project was developed as part of my frontend development learning during my internship at Xceller IT Services.

## Technologies Used
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Website Sections
- Home
- About Us
- Pet Care Services
- Team Members
- Pricing Plans
- Customer Testimonials
- Contact Section

## Pricing Plans
The website displays three pricing plans:
- Basic
- Standard
- Premium

These plans are displayed as part of the website's frontend design. They do not represent live booking or payment functionality.

## Project Type
Frontend Development Project

## Backend and Database
This is a frontend-only project. It does not include a backend, database, or server-side functionality.

## How to Run
1. Download the repository from GitHub as a ZIP file.
2. Extract the ZIP file.
3. Open the project folder in a code editor.
4. Open `index.html` in a web browser.
5. An internet connection may be needed for external libraries, fonts, and CDN resources.
